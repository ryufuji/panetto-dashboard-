## 0. システム全体像

### 0.1 3 サービスの役割

| サービス | 役割 | プラットフォーム |
|---|---|---|
| **社内ポータル (PANET)** | 全社員の人事マスター。本人プロフィール・ナレッジ・お知らせなど。アカウント発行の起点。 | Cloudflare Pages + D1 |
| **業務日報ダッシュボード** | パネット本体（PANET 法人）社員の日報・申請・期日管理 | Vercel + Supabase |
| **タス軽くん** | 店舗・系列会社（非 PANET 法人）の店舗別タスク管理 | Vercel + Neon Postgres |

### 0.2 URL 一覧

| サービス | URL |
|---|---|
| 社内ポータル (PANET) | https://panet-53v.pages.dev |
| 業務日報ダッシュボード | https://panetto-dashboard.vercel.app |
| タス軽くん | https://task-manager-one-wheat-72.vercel.app |

### 0.3 アカウント発行フロー

```
PANET (社内ポータル) でユーザー登録/編集
        │
        │ user.created / user.updated / user.archived
        ↓
     所属法人 (affiliation) を判定
        ├─ "PANET" を含む  → 業務日報ダッシュボードにアカウント発行
        ├─ "PANET" を含まない → タス軽くんにアカウント発行
        └─ 空欄 (未設定)    → どちらにも発行しない (admin が後で設定)
```

- 突合キーは `panetUserId`（PANET の数値 ID）
- 自動同期は管理画面の「⚡個別作成」「選択ユーザーのアカウントを作成」ボタン、または PANET でユーザー新規登録／編集時に自動発火
- どちらに発行されたかは PANET のユーザー一覧の **「ダッシュボード作成済 / タス軽 作成済」** バッジで確認可

## 1. 業務日報ダッシュボード — 一般ユーザー向け

### 1.1 ログイン

1. ブラウザで `https://panetto-dashboard.vercel.app/login` を開く
2. メールアドレス（または PANET 経由で発行された `dashboard_login_id`）と初期パスワードを入力
3. 初回ログイン後、パスワード変更画面が出るので変更してください

### 1.2 ヘッダーの見方

画面上部の緑色バッジ `閲覧用 〇〇 (東京/制作)` は

- 〇〇: ご自身の表示名
- 括弧内: 拠点 / 役職

を表しています。隣の admin の方には「管理画面」リンクも表示されます。

### 1.3 日報を作成する

サイドバー → 日報管理 → **日報作成** または `https://panetto-dashboard.vercel.app/dashboard/reports/new`

#### 基本情報

| 項目 | 内容 |
|---|---|
| エリア | 自分の拠点（東京 / 札幌 / 福岡 等）。プロフィールから自動セット |
| 部署 | 任意（未登録の場合は「未登録」表示・後で追加可能） |
| 氏名 | プロフィールから自動。編集不可 |
| 日付 | 既定は今日 |
| タイトル | 任意（例: A社商談・資料作成） |
| 開始 / 終了 | 出勤・退勤時刻。「現在の時間を入力」ボタンでワンクリック入力 |
| 稼働時間 (h) | 任意 |
| 全体進捗率 | 親タスクの進捗の平均から **自動計算**（手動入力不可） |

#### タブ ① 本日の業務

各「親タスク」に対して、以下が入力できます：

- **タスク名** / 詳細
- **期日** + 「本日」ボタン + 「期日なし」チェック
- **進捗 (%)** ／ **ステータス**（未着手 / 進行中 / 完了 / 保留）
- **工数 (h)**
- **目的 / 背景** — 任意のテキスト
- **省略 / 定期タスク** — フラグ
  - **「定期タスク」にチェック**を入れると、毎日同じタスクを翌日以降に自動で引き継ぎたい意図がマーク（DB 保存され、後の日報作成時に「過去の未完了タスクを全て追加」で呼び戻せる）
- **備考・メモ**
- **進行中・実績URL** — 関連 Backlog や Drive のリンク
- **共有するユーザー** — 参照だけしてほしい同僚を追加（複数可）
- **ノルマ目標 / 今日の成果** — 件数・金額の 4 マス（営業職向け）
  - 「ノルマなし」チェックで非表示にできる

##### 子タスク

親タスク右上の「**＋ 子課題**」ボタンで追加。タイトル・詳細・見積/実績/進捗/開始日/期限を入力できます。

##### 承認申請

タスクごとに「承認申請を行う」チェックを入れると、申請タイトル・カテゴリ・金額・関連ファイルURL を入れて承認フローに乗せられます（金額に応じた必要承認段数は自動算出）。

#### タブ ② 翌日以降の予定

- 自由に明日以降のタスクを記入
- **「ページ 1 の未完了タスクを追加」** — 本日タブで進捗 < 100% のタスクを翌日予定に複製
- **「過去の未完了タスクを全て追加」** — 過去レポートで未完了のものを呼び戻し（重複は自動でスキップ）
- 翌日タブには **「提出履歴」**（直近 10 件）と **「期日遅れタスク」**（未完了 / 進行中で絞り込み可）も表示

#### 下書き保存 / 送信

- **「下書き保存」**: いつでも保存できる。次回入力時に **「下書きデータを取得」** ボタンで読み込み可
- **「送信する」**: 提出。提出と同時に **LINE Works のチャンネル**へ自動通知される

#### LINE Works 通知

提出すると次のフォーマットで LINE Works に流れます（長文は 600 字単位で自動分割）：

```
【日報】2026-05-23 田中太郎

報告日：2026-05-23 18:00
勤務時間：09:30-18:00
氏名：田中太郎
所属：東京/制作
業務内容：

●【水戸ハピドリ】指名料チケット2000円(進捗70％/進行中/工数1.5h)
メモ：修正後確認中
期日：2026-05-25
証跡: https://panet.backlog.jp/view/MHD_PJ-2356

========
明日のタスク
・キャストさん名刺作成
・タスク整理
```

URL は「証跡: 」のあとに半角スペースを置いてあるため、LINE Works 側で自動リンク化されます。

### 1.4 日報を編集する

- サイドバー → 日報管理 → 日報一覧 から対象の日報を開く
- 詳細画面右上の「編集」ボタン → タスクの追加・修正・削除が可能
- 編集後「**送信**」を押すと再送される
  - 注: 初回提出時に LINE Works 通知が飛んだ後、再提出時には **重複防止のため二度目の通知は飛びません**

### 1.5 日報を閲覧する

- 日報一覧から開くだけで自動的に **閲覧記録**（report_views）が作成される
- 詳細ページの右上に「**閲覧 N人**」バッジ、下部に「**閲覧者一覧**」が表示
- 提出者本人の閲覧はカウントされません

### 1.6 期日遅れタスク

サイドバー → 日報管理 → **期日遅れタスク** で過去レポートの未完了タスクを一覧

- 「自分のみ / 組織全体」スコープ切替
- 「すべて / 未完了のみ / 進行中のみ」フィルタ
- 該当行から元の日報へ「表示」リンクで遷移可能

### 1.7 申請（経費・備品購入など）

サイドバー → 申請管理 → **申請一覧** または **新規申請**

- 「全て / 自分の申請 / 自分が承認すべき / 自分が承認済み」の 4 タブで状況を切替
- 経費購入や書類チェックなど、承認フローが必要なものを起票
- 金額に応じて承認段数（1〜3 段）が自動決定
- 承認者を指定 → 順に承認 → 完了

### 1.8 バグ報告

サイドバー最下部の **バグ報告** から、タイトル・詳細・再現手順を送信できます。

### 1.9 ガントチャート・月次レポート

サイドバー → 日報管理 → ガントチャート / 月次レポート で過去の日報を集計表示できます。

## 2. 業務日報ダッシュボード — 管理者向け

admin 権限が必要な機能をまとめます。

### 2.1 組織管理

#### エリア (拠点) を追加する

サイドバー → 組織管理 → **拠点管理** または `/dashboard/organization/offices`

- 「+ 新規作成」→ 拠点名・コード（英大文字）・住所などを入力
- 即時 DB に反映され、日報フォームのエリアセレクトに自動表示
- 既存の拠点を無効化するには `is_active=false` に設定
- 注: PANET の `area` 文字列から自動振り分ける処理は `panetto-dashboard/src/app/api/webhooks/panet-users/route.ts` の `resolveOfficeId()` にハードコードされており、新拠点を追加した際は同関数の更新が必要

#### 部署を追加する

サイドバー → 組織管理 → **部署管理** または `/dashboard/organization/departments`

- 「+ 新規作成」→ 部署名・コード・順序・管理者を入力
- 管理者 (`manager_id`) を指定しておくと、その部署のメンバーが承認申請を行う際に **デフォルト承認者として自動セット**される

#### 社員管理

`/dashboard/organization/employees`

- 全社員一覧、拠点・部署・役職・有効/無効を確認・編集
- PANET 経由で同期されているユーザーは `panet_user_id` が振られている
- 退職処理は PANET 側で archived = true にするのが正規ルート（自動で is_active=false に同期）

#### 組織図

`/dashboard/organization/chart` — 拠点・部署・社員の階層を視覚化

#### 権限管理

`/dashboard/organization/permissions` — 部署別の閲覧範囲やロール設定

### 2.2 承認設定

サイドバー → 申請管理 → **承認設定** または `/dashboard/approval-requests/settings`

- 金額別の必要承認段数を設定（例: 5,000 円未満は 1 段、5,000〜50,000 円は 2 段、それ以上は 3 段）
- 申請カテゴリ別の閾値も設定可

### 2.3 承認確認（自分が承認する役割の場合）

サイドバー → **承認確認 > 承認待ち / 承認済み**

- 承認待ち: 自分が今すぐ承認すべき申請の一覧
- 承認済み: 自分が過去に承認した申請の一覧
- 内部的には `/dashboard/approval-requests?tab=pending_approval` / `?tab=approved_by_me` にリンク

### 2.4 ダッシュボード

`/dashboard` のトップ画面に以下が並びます：

- KPI: 本日の日報 / 承認待ち申請 / 在籍人数 / 稼働店舗 / 店舗タスク
- **日報履歴** カード（直近 5 件の提出）
- **承認待ち申請** カード
- 各種統計

### 2.5 監査ログ

サイドバー → 設定 → 監査ログ — 重要操作の履歴

### 2.6 LINE Works 連携の確認

#### 環境変数

Vercel の panetto-dashboard プロジェクトに以下を設定済み：

```
LINEWORKS_CLIENT_ID
LINEWORKS_CLIENT_SECRET
LINEWORKS_SERVICE_ACCOUNT
LINEWORKS_PRIVATE_KEY
LINEWORKS_BOT_ID
LINEWORKS_CHANNEL_ID
```

#### 疎通確認

admin としてログインしたまま以下を開くと、テストメッセージが LINE Works に届きます：

```
https://panetto-dashboard.vercel.app/api/debug/lineworks-test
```

返ってきた JSON で `result.ok: true` なら正常。

#### 既存日報を再送してみる

```
https://panetto-dashboard.vercel.app/api/debug/lineworks-test?reportId=latest
```

`reportId=latest` で自分の直近の submitted 日報を対象に、`notify-submission` と同じフローを実行します（`lineworks_notified_at` を更新しないので副作用なし）。

### 2.7 日報の編集・削除

admin はすべての日報を編集・削除できます。一般ユーザーは自分のもののみ。

## 3. 社内ポータル (PANET) — 管理者向け

### 3.1 ログインと管理画面

- URL: https://panet-53v.pages.dev
- ログイン → 管理者ロールの場合は **ユーザー管理** メニューが出現
- 直接 URL: `https://panet-53v.pages.dev/admin-users.html`

### 3.2 個別ユーザー登録

「**+ 新規登録**」ボタン → メール（ログインID）・氏名・所属法人・部署・役職・入社日・誕生日 等を入力 → 作成

- 所属法人に「東京PANET」のように **PANET を含む文字列**を入れると業務日報、それ以外（例: ハピネスグループ）はタス軽くんに自動でアカウント発行
- 所属法人を空欄にすると、どちらにも発行されません（後で個別に発行可）

### 3.3 一括 Excel 登録

#### テンプレート取得

「**📊 一括登録**」→ 「テンプレートをダウンロード」→ `社内ポータル_ユーザー登録テンプレート.xlsx`

シート構成：
1. **ユーザー**シート: メール / 名前 / パスワード / **所属法人** / 部署 / 役職 / 入社日 / 誕生日 / ロール / エリア / 雇用形態
2. **所属法人の書き方**シート: 凡例（PANET 系 vs 非 PANET の例）

#### 所属法人の書き方

| パターン | 例 | 振り分け先 |
|---|---|---|
| 「PANET」を含む | 東京PANET / 福岡PANET / 札幌PANET / PANET(店舗) / 株式会社PANET | 業務日報ダッシュボード |
| 「PANET」を含まない | ハピネスグループ / (株)グーゴル / (有)初心 / (株)フロンティア | タス軽くん |
| 空欄 | — | 自動発行されない |

#### アップロード手順

1. 「一括登録」モーダルを開いて Excel ファイルを選択
2. プレビュー画面に集計が出る：
   ```
   [PANET 系 → 業務日報: N名] [非PANET → タス軽くん: N名] [所属法人 未記入: N名 ⚠]
   ```
3. 各行に **「自動発行先」列** が並び、目視確認できる
4. 問題なければ「**一括登録**」を押す
5. 新規ユーザー → 作成 + 自動発行
6. 既存ユーザー → 情報のみ更新（**自動発行は走らない**。後述の手動同期で発行）

### 3.4 アカウント未作成リストとチェック式作成

過去に登録済みで、まだ外部アカウントが発行されていない人は「**アカウント未作成**」バッジが付きます。

#### フィルタとバッジ

- ユーザー一覧上部のセレクトで「**アカウント未作成のみ / 作成済みのみ / すべて**」を切替
- 各ユーザーのバッジ:
  - 🟢 「ダッシュボード作成済」「タス軽 作成済」: 発行済み
  - 🟠 「アカウント未作成」: affiliation あり、発行可能
  - ⚪ 「所属法人未設定」: affiliation 空、発行不可（先に編集して所属を埋める必要あり）

#### 個別作成

- 各行末の **「⚡」ボタン** をクリック → 確認ダイアログ → 発行
- 所属法人が「PANET」を含むなら業務日報、含まないならタス軽くんに送られる（admin は選ばない）

#### 一括作成

- チェックボックスで複数選択 → 上部の **「選択ユーザーのアカウントを作成」** バーをクリック
- 確認ダイアログ後、順次発行。完了後に「成功 N/M (失敗 X)」のサマリ
- 「所属法人未設定」の人はチェックボックスが出ないので、誤って混入することはない

### 3.5 退職処理 (archived)

- ユーザー一覧の **🗄️ アーカイブ** ボタンで archived = true
- 自動的に下流（業務日報 or タス軽くん）の `is_active = false` に同期され、ログイン不可になる
- PANET 側で「復元」した場合も同様に同期される

### 3.6 CSV / Excel 一括連携の例

カオナビなどから出力した CSV を取り込むときは、ヘッダー名が以下のいずれかに該当すれば自動マッピングされます：

| 自動認識される列名 | 対応する内部フィールド |
|---|---|
| メール / mail | email |
| 名前 / 表示名 / name | display_name |
| パスワード / password | password |
| 所属法人 / 法人 / affiliation | affiliation |
| 部署 / department | department |
| 役職 / position / 役職名 | position |
| 入社 / join_date | join_date |
| 誕生 / birth | birth_date |
| ロール / role | role |
| エリア / area / 地域 | area |
| 雇用 / employment | employment_type |

CSV をそのまま使う場合は事前に Excel で保存し直すと文字化けを防げます。Shift-JIS の場合は UTF-8 に変換してください。

## 4. タス軽くん

### 4.1 ログイン

- URL: https://task-manager-one-wheat-72.vercel.app
- PANET 経由で発行された場合は、初期パスワード（PANET 管理画面で確認可）でログイン
- 初回はパスワード変更を推奨

### 4.2 ロール

| role | 権限 |
|---|---|
| `hq` | 本部・全店舗/全タスク閲覧可能 |
| `area_manager` | エリア統括 |
| `manager` | 担当店舗のタスク管理 |
| `member` | 自分のタスクのみ |

役職 (position) から自動的に role が決まります：

- `admin` / `社長` → `hq`
- `統括` → `area_manager`
- `店長` / `副店長` → `manager`
- `主任` / `一般` / `アルバイト` / 未設定 → `member`

### 4.3 ユーザー管理（hq 限定）

サイドバー → ユーザー管理 で：

- 全ユーザー一覧
- 個別の役職・所属店舗を編集
- PANET 経由のユーザーには `panetUserId` が紐付いている

### 4.4 タスク管理

- タスクは `店舗 (store)` + `エリア (region)` に紐づく
- 期日 / カテゴリ / 優先度 / ステータス（todo / doing / done / blocked）で管理
- コメント機能あり、変更履歴は監査ログに残る

### 4.5 PANET 経由のアカウント作成（admin 向け）

タス軽くんへのアカウント追加は通常 PANET から自動で行われます。手動で追加するには：

1. PANET 管理画面でユーザーを登録し、所属法人に「PANET」を含まない法人名を入れる
2. 業務日報ダッシュボード経由でタス軽くんの `/api/webhooks/panet-users` にフォワードされ、bcrypt パスワードで User が作成される
3. メールアドレスが衝突する既存ユーザーがある場合は `panetUserId` を紐付ける更新動作になる

## 5. 環境変数まとめ

### 5.1 業務日報ダッシュボード (Vercel)

| キー | 用途 |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase エンドポイント |

## 6. よくあるトラブルと対処

### 6.1 LINE Works 通知が届かない

1. **疎通確認**: admin として `https://panetto-dashboard.vercel.app/api/debug/lineworks-test` を開く
   - `result.ok: true` ならテストメッセージは届いている → LINE Works チャンネルを確認
   - `env` のいずれかが `false` → Vercel 環境変数を見直す
2. **実日報で再現**: `https://panetto-dashboard.vercel.app/api/debug/lineworks-test?reportId=latest` を開く
   - `error: report_select_failed` → クエリ失敗。`detail` に Postgres エラー
   - `error: format_threw` → 整形関数で例外。`detail` 確認
   - `chunk_N_of_M_failed: ...` → N 通目で API 拒否（チャンク長 / 文字種に注意）
3. **重複通知**: `reports.lineworks_notified_at` がセット済みだと再通知されない。`UPDATE reports SET lineworks_notified_at = NULL WHERE id = '...'` で再発火可

### 6.2 日報の送信ボタンを押すと 400 エラー

過去には `work_location` 等の存在しないカラムを UPDATE していたバグがありましたが解消済み。再発する場合はブラウザのコンソールで PATCH リクエストのレスポンス JSON を確認してください。

### 6.3 親タスク追加ボタンが効かない

以前 stale closure 由来の不具合がありましたが、`addTask` 等を functional updater 形式に統一して解消済み。それでも症状が出る場合は、画面を `Cmd+Shift+R`（スーパーリロード）してから試してください。

### 6.4 PANET 管理画面でアカウント作成しても発行されない

1. 「⚡」ボタンの結果ダイアログを確認。`target=none / error=affiliation_not_set` の場合 → 所属法人未設定。先に編集で入れる
2. `target=dashboard` だが LINE Works に来ない → 業務日報側の問題（→ 6.1）
3. `target=tasukaru` だが反映されない → タス軽くん側 `PANET_WEBHOOK_SECRET` の不一致を確認

### 6.5 部署プルダウンが空欄で選べない

`/dashboard/organization/departments` で部署を追加してください（admin のみ）。追加後はコード変更なしで自動的に日報フォームに出現します。

### 6.6 エリアセレクトに新しい拠点が出ない

`/dashboard/organization/offices` で「+ 新規作成」した後、以下を確認：
- `is_active=true` になっているか
- `organization_id` が現在の組織と一致しているか
- ブラウザのキャッシュをスーパーリロードでクリア
